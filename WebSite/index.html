Themes

Pick one. This page changes with it.

Plugins

Plain JavaScript. Hot reloaded.

Drop a file in ~/.lumen/plugins and it runs. Save it again and it reloads, cleanly. Commands, status items, sidebar panels, themes and CSS, with permissions you can read before enabling.

  • Notes, Clipboard and Git ship as plugins: read them, fork them
  • New plugins arrive disabled, so you review them first
  • Ask the AI to write one for you

// @name Weather
// @description The weather in the top bar.
// @version 1.0.0

module.exports = lumen => {
  let now = '…';
  lumen.statusbar.add({
    id: 'weather',
    interval: 600000,
    text: () => now
  });
  fetch('https://wttr.in/?format=%t')
    .then(r => r.text())
    .then(t => { now = t; lumen.statusbar.refresh(); });
};
